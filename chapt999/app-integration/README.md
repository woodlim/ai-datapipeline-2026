# 아로코 앱 데이터 연결

`arokor-catalog.js`는 전체 상품 원본과 전체 추천 후보를 담습니다.
현재 공식 노트와 향 계열을 확인한 향수는 Pacific Rock Moss, Bohemian Lime,
Silky Woods, Wood Infusion입니다. 공식 향 계열을 어코드 태그로 사용하며
커뮤니티 투표 기반 어코드 점수는 아닙니다. 출처와 확인일을 데이터에 기록합니다.

앱 `discover.html`에서 **상품 목록 → 아로코 추가 향수**를 선택하면 추가 상품을
확인할 수 있습니다. 주요 어코드로 필터링하고 카드에서 용량별 수집 가격과
탑·미들·베이스 노트, 공식 출처, 아로코 링크를 확인합니다.

## 데이터 갱신

1. 향수스크래핑.ipynb에서 수집·저장·앱 내보내기 셀을 실행합니다.
2. 향 정보는 `data/arokor_enrichment.json`에 추가합니다. 향수 하나에 용량별
   상품 번호를 `product_ids`로 연결합니다. 엘릭서, 세트, 농도가 다른 상품은
   별도 확인 없이 같은 향수에 묶지 않습니다.
3. 생성된 `arokor-catalog.js`를 앱 루트와 `mobile-build`에 복사합니다.
4. 앱을 배포할 때는 서비스워커 캐시 버전도 갱신합니다.

전체 상품을 추천 후보에 넣습니다. 같은 이름의 단일 용량 상품은 한 카드로 묶고,
세트·엘릭서·다른 농도는 별도 상품으로 유지합니다. 미확인 향 정보는 null 또는
빈 어코드 목록, `profile: "unknown"`으로 저장하고 화면에는 ‘확인 전’으로 표시합니다.
‘모든 향 둘러보기’에서는 미확인 상품도 추천하고, 특정 향 분위기나 어코드를
고를 때는 해당 정보가 확인된 상품을 대상으로 합니다. 확인 전 필터도 제공합니다.
보유 상품과 전 용량 품절 상품은 기존 동작대로 추천에서 제외합니다.
가격은 수집 스냅샷이며 실제 가격과 재고는 상품 페이지에서 확인합니다.
기존 `wood-mobile-app.zip`은 다시 패키징하지 않았습니다.

## 검증

저장소 루트에서 다음 명령으로 실제 앱 파일을 테스트합니다.

```powershell
node chapt999/app-integration/integration.test.cjs 'C:\Users\User\Documents\ChatGPT\향수 프로젝트'
```

추천 카탈로그 연결, 용량 통합, 어코드 필터, 작은 목록 새로고침,
보유 향수 제외, 전 용량 품절 제외, 카드의 향 계열·가격 표시를 확인합니다.
